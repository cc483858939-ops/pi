# Code Review

Use this skill when reviewing an implementation or commit.

Guidelines:

- Inspect the actual diff.
- Prioritize correctness, regressions, and missing tests.
- Separate confirmed defects from design preferences.
- Do not claim CI passed without evidence.
- Keep findings scoped to the requested change.
