# Testing

Use this skill when modifying code that needs validation.

Guidelines:

- Inspect existing tests before changing behavior.
- Add a regression test for confirmed bugs.
- Run the narrowest relevant test first.
- Run the project validation command before completion.
- Do not claim tests passed unless they were actually executed.
